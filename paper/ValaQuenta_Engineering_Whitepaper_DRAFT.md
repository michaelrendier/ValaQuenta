The problem this paper engineers against is drift: the same constants, symbols and operators are re-typed in dozens of files and repositories, with different names for the same value and the same name for different values. ## 1. Problem and approach

A research repository that grows by building tools first accumulates copies. By 2026-11 the constant d* = 0.24600 was written in about 120 code files across ten repositories; the value 0.5671432904 (the Lambert W fixed point) was named `OMEGA_ZS` in the code and A_π in the author's notation; the value 1/137.036 was named `A_PI`; and the symbol σ meant at least eight different objects. A change to one file did not reach the others, and a search for σ returned the wrong context.

The approach is to make the repository the code root. ValaQuenta holds the single source of every constant (`engine/constants.py`); each engine imports from it; documentation is a code reference generated from the engines and checked by tests; and a propagation tool (`tools/propagate.py`) carries a change to every downstream use, working-tree only, with a ledger. Every file that uses d* in any form carries the same four-line block listing all four values of d* and the location of the full account. Every σ carries its own identifier: `sigma_riemann`, `sigma_rb`, `sigma_self`, `sigma_valuation`, `sigma_stratum`, `sigma_expansion`, `sigma_std`. Engines are documented in dependency order, so a result is stated after the code it uses.

### 6.1 The address: `hw_address`, `hw_to_t32` — Convention B

A decimal string is read as a bijective base-97 number over a 97-character QWERTY-row table (digits '1'…'9','0' have indices 1…10); the 0-based address is cut to its low 32 bits, which is the word. The table is copied by `repr()` from the module, not retyped.

### 6.2 The multiplication: `t32_mul` — Convention B, with the whole small table (F)

Cayley-Dickson doubling over GF(2): a word of d bits is a pair of words of d/2 bits, and (a₁, a₂)(b₁, b₂) = (a₁b₁ ⊕ b₂a₂, b₂a₁ ⊕ a₂b₁), with the one-bit product being AND. This is the construction that gives ℝ → ℂ → ℍ → 𝕆 → 𝕊 over the reals, one doubling further, over a field of two elements.

### 6.3 The square law and the detector: `square_class`, `trace_laplacian`, `radical_census` — Convention B, then D

Every word w satisfies w·w ∈ {0, e₀} (e₀ is the word 1): w is nilpotent, or an involutory unit. The detector Δ(w) = w·𝟏, with 𝟏 the all-ones word, vanishes exactly when w·w = 0. 𝟏 is not an annihilator (e₀·𝟏 = 𝟏); the earlier lemma that it is, in the UDEO white paper, is retracted (2026-08-22).

**The rule behind the law, found by chasing the two-digit anomaly of §6.4 to its source** (`:CALCULATED`): w·w = (number of 1 bits of w, mod 2)·e₀. A word is nilpotent exactly when it has an even number of 1 bits. The weight parity is a ring homomorphism to GF(2) (parity(a·b) = parity(a)·parity(b), every pair at d ≤ 8), Δ(w) = parity(w)·𝟏, and the radical is its kernel: the even-weight words, closed under XOR, of dimension d − 1. Checked exhaustively at d ≤ 16 (every pair at d ≤ 8) and on 20,000 words at d = 32; not proved here. (An earlier draft of this section said no closed form was known; that is withdrawn, ledger X-63.) The nilpotency indicator of a Hyperwebster word is therefore the Thue-Morse sequence of the address.

### 7.2 The Niemeier gap: `niemeier_root_systems`, `niemeier_gap_theorem` — Convention B, then E

The claim under the N-shape is one finite fact about the numbers 24 and 16. Take every A/D/E root system of rank 24 whose irreducible components all have one Coxeter number h (A_n has h = n + 1, D_n has 2n − 2, E6, E7, E8 have 12, 18, 30). There are exactly 23 (Niemeier 1973; the Leech lattice has none). Reduce h modulo 16, the number of sedenion places.

**Theorem** (`ESTABLISHED`, proof below, and checked by the listing). h mod 16 is never 1, 11 or 15.

*Proof.* D_n and E_n have even Coxeter number, so an odd h forces every component to be A_(h−1); k copies of A_(h−1) have rank k(h − 1) = 24, so (h − 1) divides 24. The divisors of 24 are 1, 2, 3, 4, 6, 8, 12, 24, which give the odd h = 3, 5, 7, 9, 13, 25, congruent to 3, 5, 7, 9, 13, 9 modulo 16. An even h is never congruent to an odd residue. Hence the odd residues 1, 11, 15 are never reached. ∎

The listing does not type in the 23: it generates them from the defining condition (a coin-change over the components with a given h) and then checks each step of the proof against what it found.

```python
        out.append((f'D{(h + 2) // 2}', (h + 2) // 2))
    for name, rank, coxeter in (('E6', 6, 12), ('E7', 7, 18), ('E8', 8, 30)):
        if coxeter == h and rank <= max_rank:
            out.append((name, rank))
    return out

def niemeier_root_systems(rank=24):
    found = []
    for h in range(2, 2 * rank):
        comps = _components(h, rank)

        def split(i, left, chosen):
            if left == 0:
                if chosen:
                    found.append((h, dict(chosen)))
                return
            if i == len(comps):
                return
            name, r = comps[i]
            for k in range(left // r, -1, -1):
                split(i + 1, left - k * r, chosen + ([(name, k)] if k else []))
        split(0, rank, [])
    return [{'h': h, 'multiplicities': m, 'label': ' '.join((f'{n}^{k}' if k > 1 else n for n, k in m.items()))} for h, m in sorted(found, key=lambda t: (t[0], str(t[1])))]

def niemeier_gap_theorem(rank=24, modulus=16):
    systems = niemeier_root_systems(rank)
    hs = sorted({s['h'] for s in systems})
    reached = sorted({h % modulus for h in hs})
    gap = sorted(set(range(modulus)) - set(reached))
    odd_h = sorted((h for h in hs if h % 2))
    divisors = [d for d in range(1, rank + 1) if rank % d == 0]
    odd_from_divisors = sorted((d + 1 for d in divisors if (d + 1) % 2))
    only_a = all((len(s['multiplicities']) == 1 and next(iter(s['multiplicities'])).startswith('A') for s in systems if s['h'] % 2))
    max_h = max(2 * rank - 2, rank + 1, 30)
    return {'root_systems': systems, 'count': len(systems), 'h_values': hs, 'max_h_possible': max_h, 'residues_reached': reached, 'gap': gap, 'proof': {'odd_h_means_every_component_is_A': only_a, 'divisors_of_rank': divisors, 'odd_h_from_divisors': odd_from_divisors, 'odd_h_found': odd_h, 'odd_h_residues': sorted({h % modulus for h in odd_h})}, 'theorem_holds': len(systems) == 23 and odd_h == odd_from_divisors and only_a and (gap == [1, 11, 15])}

t = niemeier_gap_theorem()
print(t['count'], 'root systems; h =', t['h_values'])
print('residues reached mod 16:', t['residues_reached'])
print('gap:', t['gap'])
print('odd h from (h-1) | 24:', t['proof']['odd_h_from_divisors'], '; odd h found:', t['proof']['odd_h_found'])
print('theorem holds:', t['theorem_holds'])
```

### 7.5 The n-ball and the Gamma function: `bell_curve.nball_volume`, `nsphere_area`, `nball_peak` — Convention B

Gamma reaches this engine as the bookkeeping of a hypersphere. The Gaussian integral of e^(−|x|²) over R^n is (√π)^n; in spherical coordinates it equals (S/2)·Γ(n/2), where S is the area of the unit sphere. So S(n) = 2π^(n/2)/Γ(n/2) and the unit ball has volume V(n) = π^(n/2)/Γ(n/2 + 1) = S(n)/n, for every real n (`ESTABLISHED`). At n = 2 these are π and 2π, the circle. The three functions live in `bell_curve` because that engine is the one stdlib-only home of the special functions (`math.lgamma`), and every engine that uses Gamma imports it from there.

**Listing 13 — the unit n-ball and its peak** (`modules/bell_curve/maths.py: nball_volume, nsphere_area, nball_peak`; extracted, 19 lines, executed cold)

```python
import math

def nball_volume(n):
    return math.exp(0.5 * n * math.log(math.pi) - math.lgamma(0.5 * n + 1.0))

def nsphere_area(n):
    return 2.0 * math.exp(0.5 * n * math.log(math.pi) - math.lgamma(0.5 * n))

def nball_peak(which='volume'):
    f = nball_volume if which == 'volume' else nsphere_area
    lo, hi, h = (1.0, 12.0, 1e-05)
    g = lambda n: math.log(f(n + h)) - math.log(f(n - h))
    for _ in range(100):
        mid = 0.5 * (lo + hi)
        if g(mid) > 0:
            lo = mid
        else:
            hi = mid
    return 0.5 * (lo + hi)

for n in (1, 2, 3, 8, 16):
    print(n, round(nball_volume(n), 6), round(nsphere_area(n), 6))
print('V peaks at n =', round(nball_peak('volume'), 7), '; S peaks at n =', round(nball_peak('area'), 7))
```
