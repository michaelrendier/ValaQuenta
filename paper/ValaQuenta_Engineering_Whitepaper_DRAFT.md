## Abstract

ValaQuenta is a Python code repository of 54 equation engines, each a directory with a manifest, a maths module, a tools module, a wiki page and a notebook, registered through one registry. The problem this paper engineers against is drift: the same constants, symbols and operators are re-typed in dozens of files and repositories, with different names for the same value and the same name for different values. The paper documents the repository as a code reference: the engine contract, the single source of constants, and then each engine with the code that runs, the transcript it prints, and the tests that check it. Engine 0 is the constants file; engine 1 is Ĥ_RB, the operator whose two currents J_red (the Noether current) and J_blue (the Noether information current) satisfy Ĥ_RB − Ĥ_BR = J_red + J_blue.

## 1. Problem and approach

A research repository that grows by building tools first accumulates copies. By 2026-11 the constant d* = 0.24600 was written in about 120 code files across ten repositories; the value 0.5671432904 (the Lambert W fixed point) was named `OMEGA_ZS` in the code and A_π in the author's notation; the value 1/137.036 was named `A_PI`; and the symbol σ meant at least eight different objects. A change to one file did not reach the others, and a search for σ returned the wrong context.

The approach is to make the repository the code root. ValaQuenta holds the single source of every constant (`engine/constants.py`); each engine imports from it; documentation is a code reference generated from the engines and checked by tests; and a propagation tool (`tools/propagate.py`) carries a change to every downstream use, working-tree only, with a ledger. Every file that uses d* in any form carries the same four-line block listing all four values of d* and the location of the full account. Every σ carries its own identifier: `sigma_riemann`, `sigma_rb`, `sigma_self`, `sigma_valuation`, `sigma_stratum`, `sigma_expansion`, `sigma_std`. Engines are documented in dependency order, so a result is stated after the code it uses.

## 2. The engine contract

An engine is a directory `modules/<name>/` with `manifest.json` (schema `valaquenta.plugin/1`, [`FORMAT.md`](https://github.com/michaelrendier/ValaQuenta/blob/main/FORMAT.md)), `maths.py` (pure functions), `tools.py` (an `EquationModule` subclass exposing `formulary()`), a wiki page in API style, a toolbox page generated by `tools/gen_toolbox.py`, and a notebook. `from ValaQuenta.__main__ import _register_all` registers every engine; `registry.run('<engine>.<equation>', params)` runs one equation. This contract is Convention A: the paper names it and points at the files.

#### 3.3.1 The address: `hw_address`, `hw_to_t32` — Convention B

A decimal string is read as a bijective base-97 number over a 97-character QWERTY-row table (digits '1'…'9','0' have indices 1…10); the 0-based address is cut to its low 32 bits, which is the word. The table is copied by `repr()` from the module, not retyped.

**Listing 7 — integer → Hyperwebster address → 32-bit word** (`modules/t32_nilpotency/maths.py: hw_address, hw_to_t32`; extracted, 13 lines, executed cold)

```python
_HW_CHARS = '`1234567890-=\tqwertyuiop[]\\asdfghjkl;\'\nzxcvbnm,./ ~!@#$%^&*()_+QWERTYUIOP{}|ASDFGHJKL:"ZXCVBNM<>?'
_HW_IDX = {ch: i for i, ch in enumerate(_HW_CHARS)}
_HW_N = len(_HW_CHARS)

def hw_address(n):
    text = str(n)
    address = 0
    for i, ch in enumerate(reversed(text)):
        address += (_HW_IDX[ch] + 1) * _HW_N ** i
    return address - 1

def hw_to_t32(n):
    return hw_address(n) & 4294967295

for n in (2, 11, 101, 99991):
    print(n, hw_address(n), hex(hw_to_t32(n)))
```

```
2 2 0x2
11 195 0xc3
101 19886 0x4dae
99991 894514601 0x355135a9
```

The mapping from integers to words is not injective once the address passes 2³² ≈ 4.3·10⁹: the largest five-digit address is below it (0.21 · 2³²) and every six-digit integer is above it (at least 2·97⁵ ≈ 1.7·10¹⁰), so the words of integers of six or more decimal digits are truncated. The windows of §3.3.4 stop at five digits and are not affected.

#### 3.3.2 The multiplication: `t32_mul` — Convention B, with the whole small table (F)

Cayley-Dickson doubling over GF(2): a word of d bits is a pair of words of d/2 bits, and (a₁, a₂)(b₁, b₂) = (a₁b₁ ⊕ b₂a₂, b₂a₁ ⊕ a₂b₁), with the one-bit product being AND. This is the construction that gives ℝ → ℂ → ℍ → 𝕆 → 𝕊 over the reals, one doubling further, over a field of two elements.

**Listing 8 — Cayley-Dickson multiplication over GF(2), and the whole table at d = 2** (`modules/t32_nilpotency/maths.py: t32_mul`; extracted, 12 lines, executed cold)

```python


def t32_mul(a, b, dim=32):
    if dim == 1:
        return a & b
    half = dim >> 1
    mask = (1 << half) - 1
    a1, a2 = (a & mask, a >> half)
    b1, b2 = (b & mask, b >> half)
    lo = t32_mul(a1, b1, half) ^ t32_mul(b2, a2, half)
    hi = t32_mul(b2, a1, half) ^ t32_mul(a2, b1, half)
    return lo | hi << half

for a in range(4):
    print(' '.join(str(t32_mul(a, b, 2)) for b in range(4)))
```

```
0 1 2 3
0 2 1 3
0 3 3 0
```

The whole d = 2 table is the exhaustive small case: four words, 16 products, 1 ordered pair of nonzero zero divisors (a = b = 3, since 3·3 = 0). At d = 4 there are 25 such pairs and at d = 8 there are 2,689; the algebra is commutative at d = 2, 4, 8 (checked for every pair, `tests/test_t32_nilpotency.py`).

#### 3.3.3 The square law and the detector: `square_class`, `trace_laplacian`, `radical_census` — Convention B, then D

Every word w satisfies w·w ∈ {0, e₀} (e₀ is the word 1): w is nilpotent, or an involutory unit. The detector Δ(w) = w·𝟏, with 𝟏 the all-ones word, vanishes exactly when w·w = 0. 𝟏 is not an annihilator (e₀·𝟏 = 𝟏); the earlier lemma that it is, in the UDEO white paper, is retracted (2026-08-22).

**Listing 9 — the square law, the detector, the census** (`modules/t32_nilpotency/maths.py: ones, trace_laplacian, square_class, radical_census`; extracted, 33 lines, executed cold)

```python


def t32_mul(a, b, dim=32):
    if dim == 1:
        return a & b
    half = dim >> 1
    mask = (1 << half) - 1
    a1, a2 = (a & mask, a >> half)
    b1, b2 = (b & mask, b >> half)
    lo = t32_mul(a1, b1, half) ^ t32_mul(b2, a2, half)
    hi = t32_mul(b2, a1, half) ^ t32_mul(a2, b1, half)
    return lo | hi << half

def ones(dim=32):
    return (1 << dim) - 1

def trace_laplacian(w, dim=32):
    return t32_mul(w, ones(dim), dim)

def square_class(w, dim=32):
    sq = t32_mul(w, w, dim)
    return 'nilpotent' if sq == 0 else 'involutory' if sq == 1 else 'other'

def radical_census(dim=8):
    if dim > 16:
        raise ValueError('radical_census enumerates 2**dim words; dim must be <= 16')
    counts = {'nilpotent': 0, 'involutory': 0, 'other': 0}
    agrees = True
    for w in range(1 << dim):
        counts[square_class(w, dim)] += 1
        agrees &= (trace_laplacian(w, dim) == 0) == (t32_mul(w, w, dim) == 0)
    one = ones(dim)
    return {'dim': dim, 'words': 1 << dim, **counts, 'detector_agrees': agrees, 'one_is_annihilator': t32_mul(1, one, dim) == 0}

for d in (2, 4, 8):
    print(radical_census(d))
import random
r = random.Random(1)
ws = [r.getrandbits(32) for _ in range(20000)]
print('d = 32, 20000 words: detector mismatches =', sum((trace_laplacian(w) == 0) != (square_class(w) == 'nilpotent') for w in ws), '; classes', sorted({square_class(w) for w in ws}))
```

#### 3.3.4 The prime words and the control: `nilpotency_window`, `matched_prime_control` — Convention D

The earlier page compared the five Niemeier-gap primes (11, 17, 31, 47, 59), all nilpotent, with a "70 % baseline" that was the observed rate of the other Moonshine primes. That is not a chance rate. By the square law a random word is nilpotent half the time; the controls below are the magnitude-matched kind that the factoring use of this mechanism had failed (`hypergon_constructibility`).

**Listing 10 — primes against composites by decimal length, and the prime-matched control** (`modules/t32_nilpotency/maths.py: sieve, t32_mul, is_nilpotent, hw_address, hw_to_t32, nilpotency_window, matched_prime_control`; extracted, 60 lines, executed cold)

```python
from typing import List
_HW_CHARS = '`1234567890-=\tqwertyuiop[]\\asdfghjkl;\'\nzxcvbnm,./ ~!@#$%^&*()_+QWERTYUIOP{}|ASDFGHJKL:"ZXCVBNM<>?'
_HW_IDX = {ch: i for i, ch in enumerate(_HW_CHARS)}
_HW_N = len(_HW_CHARS)

def sieve(limit):
    is_p = bytearray([1]) * (limit + 1)
    is_p[0] = is_p[1] = 0
    for i in range(2, int(limit ** 0.5) + 1):
        if is_p[i]:
            is_p[i * i::i] = bytearray(len(is_p[i * i::i]))
    return [i for i, v in enumerate(is_p) if v]

def t32_mul(a, b, dim=32):
    if dim == 1:
        return a & b
    half = dim >> 1
    mask = (1 << half) - 1
    a1, a2 = (a & mask, a >> half)
    b1, b2 = (b & mask, b >> half)
    lo = t32_mul(a1, b1, half) ^ t32_mul(b2, a2, half)
    hi = t32_mul(b2, a1, half) ^ t32_mul(a2, b1, half)
    return lo | hi << half

def is_nilpotent(a):
    return a != 0 and t32_mul(a, a) == 0

def hw_address(n):
    text = str(n)
    address = 0
    for i, ch in enumerate(reversed(text)):
        address += (_HW_IDX[ch] + 1) * _HW_N ** i
    return address - 1

def hw_to_t32(n):
    return hw_address(n) & 4294967295

def nilpotency_window(lo, hi):
    is_p = set(sieve(hi))

    def tally(ns):
        ns = list(ns)
        k = sum((is_nilpotent(hw_to_t32(n)) or hw_to_t32(n) == 0 for n in ns))
        return {'nilpotent': k, 'n': len(ns), 'rate': k / len(ns) if ns else 0.0}
    pr = [n for n in range(lo, hi) if n in is_p]
    co = [n for n in range(lo, hi) if n not in is_p]
    return {'lo': lo, 'hi': hi, 'primes': tally(pr), 'composites': tally(co), 'composites_ending_1379': tally((n for n in co if n % 10 in (1, 3, 7, 9)))}

def matched_prime_control(subset, trials=20000, seed=1):
    import random
    rng = random.Random(seed)
    pool = sieve(max(subset))
    nil = {p: is_nilpotent(hw_to_t32(p)) or hw_to_t32(p) == 0 for p in pool}
    obs = sum((nil[p] for p in subset))
    ge = al = 0
    for _ in range(trials):
        k = sum((nil[p] for p in rng.sample(pool, len(subset))))
        ge += k >= obs
        al += k == len(subset)
    return {'observed': obs, 'n': len(subset), 'pool_size': len(pool), 'p_at_least': ge / trials, 'p_all': al / trials, 'random_word_rate': 0.5}

for lo, hi in ((10, 100), (100, 1000), (1000, 10000)):
    w = nilpotency_window(lo, hi)
    print(lo, hi, {k: (v['nilpotent'], v['n']) for k, v in w.items() if isinstance(v, dict)})
print(matched_prime_control([11, 17, 31, 47, 59]))
```
