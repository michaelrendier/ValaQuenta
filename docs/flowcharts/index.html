ValaQuenta: code flow of every engine

One chart per engine, derived from the source by ast (tools/flowchart.py); nothing is hand-drawn. Every title is a name that exists in the code and every arrow is a call found in it. Lanes are the engine's source files, left to right; the last lanes are other engines and stored data. A picture shows the machinery; it is not evidence that the mathematics is right.

How to read them. ISO 5807:1985 symbols: oval = the registry class, rectangle = a public function, double-barred rectangle = a function of another engine, cylinder = a data file. Drawn with tools/flowlib.py; same style as the Monad and Harness charts in VAPMIP. Python conventions follow PEP 8, PEP 257 and the Python documentation.
